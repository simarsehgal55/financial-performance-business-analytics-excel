# Financial Performance & Business Analytics | Excel

## Project Overview

This project uses Microsoft Excel to analyse sales and profitability data across different time periods, regions, categories, sub-categories, products, and customers. The analysis uses Excel-based techniques to identify business performance trends and generate actionable insights.

## Objectives

- Analyse sales and profitability performance
- Identify sales and profit trends over time
- Compare regional and state-level performance
- Analyse category and sub-category performance
- Identify high-performing products and customers
- Develop a dashboard for business performance monitoring

## Tools & Techniques

- Microsoft Excel
- PivotTables
- Pivot Charts
- GETPIVOTDATA
- VLOOKUP
- Calculated Metrics
- Data Analysis
- Dashboard Development

## Analysis Areas

- Sales Performance
- Profitability Analysis
- Regional & State Analysis
- Category & Sub-Category Analysis
- Product Performance
- Customer Performance
- Time-Based Analysis

## Key Insights

- Identified variations in sales and profitability across time periods and regions
- Analysed categories and sub-categories contributing to business performance
- Identified high-performing and underperforming products
- Analysed customer-level sales contribution
- Compared sales performance with profitability
